# ipfs2fil public demo archive

A public sample archive for the ipfs2fil docs: a bit of every kind of file
the explorer can show. Everything here is in the public domain or under an
open license that allows sharing it unchanged.

| Folder | What | Source and license |
|---|---|---|
| `images/` | Fractals, flow fields, mosaics, Truchet tiles (SVG), sprites, animated GIFs | Generated for this archive, CC0 |
| `photos/nasa/` | Hubble, Webb, Mars, Earth, Apollo, Cassini images | NASA, public domain; see `photos/nasa/CREDITS.txt` |
| `video/nasa/` | Short NASA videos | NASA, public domain |
| `music/chopin/` | Chopin piano works | Musopen, CC0 (archive.org/details/musopen-chopin) |
| `music/synth/` | Five short tracks in mp3, ogg, flac, m4a and wav | Synthesized for this archive, CC0 |
| `books/` | Classic novels as EPUB | Project Gutenberg (public-domain texts, gutenberg.org/policy/license) |
| `books/little-brother-cory-doctorow.epub` | Little Brother, Cory Doctorow | CC BY-NC-SA 3.0, from craphound.com |
| `papers/` | The IPFS, Filecoin and Bitcoin papers | arXiv 1407.3561 (J. Benet), filecoin.io (Protocol Labs), bitcoin.org (S. Nakamoto, MIT) |
| `papers/rfc/` | RFC 1, 675, 791, 1958, 2324, 2616, 8890 printed to PDF | IETF; RFCs may be copied and distributed unchanged |
| `games/` | 2048, Hextris, Clumsy Bird, Javascript Racer, A Dark Room: open each folder's `index.html` | Open source; each folder keeps its own LICENSE (MIT, GPL-3.0, MPL-2.0) |
